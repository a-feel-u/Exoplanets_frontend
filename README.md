# Exoplanets_frontend

## О проекте

Frontend SPA-приложения для просмотра каталога экзопланет.

Проект разработан в рамках лабораторной работы №5 с использованием React, TypeScript и React-Bootstrap.

Данные об экзопланетах загружаются из локальной mock-коллекции. Подключение к Go-бэкенду в этой лабораторной не используется.

## Используемые технологии

- React
- TypeScript
- Vite
- React-Bootstrap
- Bootstrap
- React Router DOM

## Страницы приложения

### 1. Лента экзопланет

Адрес: `/`

Страница отображает экзопланеты в формате вертикальной ленты.

Информация на странице:
- Название экзопланеты.
- Описание.
- Расстояние до звезды.
- Масса экзопланеты.
- Видео экзопланеты.

Элементы управления:
- «Читать далее» — раскрывает полное описание.
- Кнопка со стрелкой — переключает ленту на следующую экзопланету.

Также страницу можно открыть с конкретной планетой по адресу `/feed/:id`.

### 2. Каталог экзопланет

Адрес: `/grid`

Страница отображает экзопланеты в виде сетки из двух колонок.

Элементы управления:
- Поле поиска — поиск по названию и описанию.
- Кнопка «Найти» — применяет введённый запрос.
- Выпадающий список фильтров:
  - Все экзопланеты.
  - Близкие (расстояние до 10 а. е.).
  - Далёкие (расстояние более 10 а. е.).
  - Масса меньше 1.
  - Масса от 1 и выше.
- Кнопка «Подробнее» — открывает ленту с выбранной экзопланетой.

### 3. Добавление экзопланеты

Адрес: `/add`

Страница подготовлена как отдельный маршрут приложения.

На текущем этапе отображается демонстрационная заготовка. Реальное добавление данных и отправка файлов на сервер не реализуются.

## Нижняя навигационная панель

Панель содержит четыре пункта:

- Лента — доступна.
- Добавление — недоступно.
- Плитка — доступна.
- Вход — недоступен.

## Mock-данные

Все карточки формируются из массива `EXOPLANETS_MOCK`, расположенного в `src/modules/mock.ts`.

Структура объекта экзопланеты описана в `src/types/exoplanet.ts`.

Данные не загружаются из Go API.

## Медиафайлы по умолчанию

Если у экзопланеты отсутствует изображение, используется локальный файл `public/DefaultImage.png`.

Если отсутствует видео, используется `public/DefaultVideo.mp4`.

## React-компоненты и props

### Filter

Компонент фильтрации. Получает через props:
- searchValue;
- onSearchChange;
- selectedFilter;
- onFilterChange;
- onSearchSubmit.

### ExoplanetCard

Компонент карточки экзопланеты. Получает объект `exoplanet` через props и отображает его характеристики.

## Используемые хуки

- useState — хранение состояния компонентов.
- useEffect — выполнение действия при изменении ID экзопланеты.
- useMemo — оптимизация фильтрации.

## Запуск проекта

Установка зависимостей:

```bash
npm install
```

Запуск приложения:

```bash
npm run dev
```

Сборка проекта:

```bash
npm run build
```
